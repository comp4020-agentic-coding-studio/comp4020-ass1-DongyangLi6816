Ten Years Late

整支希腊舰队同一天离开特洛伊。狄俄墨得斯第四天就到家了。
这个网站只做一件事：让你亲手把他们拉开。

狄俄墨得斯，第 4 天到家。（第 3 卷）
墨涅拉俄斯，第 8 年。（第 4 卷）
奥德修斯，第 20 年。
中间那段，就是《奥德赛》。

v2 改了什么

  • 幽灵船不再是一艘，是一支舰队。荷马自己把对照组写好了——见 04
  • 基准线补上了：≈ 一周，两个互相独立的锚点
  • 产图方案推翻重来：原假设「古人画怪物不画等待」被证据推翻，换成一条更准也更有用的原则——见 06

01

核心机制：一个滑块，两艘船

访客只操作一个原生滑块。拖动它，地图上两艘船同时移动：

幽灵船 · the voyage that should have happened

虚线轮廓，冷灰色。从特洛伊直航伊萨卡。它会在很靠前的位置抵达并停住，然后一直停在那里，旁边的计数器开始跑：waiting at Ithaca · 2,537 days。

它不动，才是论点。

实船 · what Homer actually wrote

实线，陶红色。走 research 里那 18 项全部行程。它会在喀耳刻岛停一年不动，在奥吉吉亚岛停七年不动，而独眼巨人、塞壬、斯库拉这些最有名的段落一瞬而过。

为什么幽灵船比数字有效

「七年」是一个抽象量。但「你拖了半个屏幕，那艘灰船一直停在终点等着」是一个可以被身体感知的量。这就是 brief 里说的 interaction doing real work——交互不是内容的包装，交互就是论证。

03

最难的一处：等比时间尺会毁掉可用性

如果滑块线性映射到真实天数（0 → 3,034），会发生这个：

按真实天数等比 —— 真实，但没法用
· · Circe 365d · Ogygia 2,576d

独眼巨人、塞壬、斯库拉在原文里一个天数都没给，所以它们的宽度是 0 像素——根本拖不到。奥吉吉亚吃掉 85%。

解法：控制均匀，显示等比，两行同屏

不加第二个控件（brief 要求 one mechanic），而是让一个滑块驱动两行：

① 控制行 · beat index 0–28 · 均匀 · 这是你拖的东西
TroyCicLot CyclopsAeoLae CirceUnderSiren ScyThrinOgy PhaIth
② 日历行 · 真实天数等比 · 只读 · 这是真相
顺利到家 · Circe 一年 · · Ogygia 七年 ·

拖动时，①行的游标匀速前进，②行的游标几乎不动，然后突然跳一大段。两个游标的错位是永久可见的，不需要任何解说词。斜纹段 = 原文没给时长。

04

幽灵船的基准线

荷马自己把对照组写好了。而且写在同一场对话里——涅斯托耳对忒勒马科斯讲述返航时，同时讲了顺利的和毁掉的，由一个两者都经历过的人说出来。

谁用了多久出处状态
狄俄墨得斯 → 阿尔戈斯第 4 天第 3 卷原文明确 ✅
涅斯托耳 → 皮洛斯未记载第 3 卷路线全给了，"顺风一路没停"
墨涅拉俄斯 → 斯巴达第 8 年第 3、4 卷原文明确 ✅
阿伽门农 → 迈锡尼未记载第 4 卷到家当天被杀
埃阿斯—第 4 卷途中溺死
奥德修斯 → 伊萨卡第 20 年全书 5 处原文明确 ✅

覆盖率：荷马写到的返航共 13 条，其中只有 3 条给了明确时长。另有 6 位在其他古代文献里有返航记载但《奥德赛》完全没提（Teucer、Menestheus、Calchas 等），属于失传的《Nostoi》和阿波罗多洛斯——页面上若说"其他将领的返航"，必须说明这是荷马的子集，不是全部传统。

荷马自己给了总账

第 4 卷，普罗透斯对墨涅拉俄斯：

"only two of the chief men among the Achaeans perished during their return home… A third Achaean leader is still at sea, alive, but hindered from returning."

回程只死了两位主将，其余都到家了，只剩一个还在海上。奥德修斯是明确的例外，不是代表——这句话把幽灵船从"假设"变成了文本事实。

锚点一 · 原文

Butler："Four days later Diomed and his men stationed their ships in Argos"

⚠️ 希腊原文 τετράτῳ ἤματι 是「在第四天」（Murray 的 Loeb 同）。"四天之后"（间隔）和"第四天抵达"（日期）不是一回事——用希腊文读法，并注明 Butler 有出入。另外第四天是从 Geraestus 算还是从渡海起算，原文没定，留开不要选。

锚点二 · 实测

Casson 的古代航行记录表里有一条从特洛伊出发的实航：特洛伊→亚历山大港，550 海里，7 天，3.0 节（p.293）。特洛伊→伊萨卡是 565 海里，只远 2.7%。

7 × 565/550 = 7.2 天 inferred

唯一的推断只是把一条实测航程缩放 2.7%——比"距离÷假设航速"强得多。

⚠ 三条必须印在页面上的警告

  • 青铜时代警告。Casson 全部航速数据是希腊-罗马圆底商船（前 1 世纪–公元 5 世纪）。荷马时代是二十/三十桨的桨帆船，每晚拖上岸。Casson p.279 n.37："我们没有任何关于古代桨帆船能冲多快的资料。" 所以「4–6 节」套到奥德修斯船上是外推，必须标注。
  • 荷马的航速是英雄式的，不是历史的。忒勒马科斯一夜跑完伊萨卡→皮洛斯 197.5 km，反推 7.6–10.7 节 inferred——高于 Casson 单船速度，更别说舰队。第 4 卷还把法罗斯放在离埃及一天航程外，而它就在亚历山大港岸边。地理和航速在实测下都会崩——这正是幽灵船必须用实测数据而非荷马自己航速的理由。
  • 「十年漂泊」是推算，原文从没说过。只说"离开伊萨卡二十年"和"打九年、第十年攻陷后启航"。20 − 10 = 10 inferred。既然站名就叫 Ten Years Late，这个标注不能省。

设计含义：幽灵船不该只有一艘

时间轴上并排放整支希腊军队的返航。这仍然是一个 idea：所有人都到家了，各花了多久——现在看奥德修斯。

而且这条光谱本身有内容：墨涅拉俄斯也慢，但他慢是因为在埃及、腓尼基、利比亚一路收集财宝——他是选择的。奥德修斯是被困的。同样的年数，两种完全不同的东西。

距离 565 海里来自 Hal Roth（We Followed Odysseus，实际驾 35 尺帆船重走此线），现代测量，非古代数字；27 航点大圆累加独立校验得 576 海里，差 +2.0%。绕伯罗奔尼撒是必须的——科林斯运河 1893 年才通。

06

图：一个被推翻的假设，和一条更好的原则

✗ 撤回：「古人画怪物，没人画等待」

这条假设被 LIMC 的目录数据推翻了。原样记录，因为撤回本身是过程证据：

条目目录数（下限）它是什么
喀耳刻 Kirke≥71整整一年的停留——Odyssey 专属条目里最大的一个
波吕斐摩斯≥66几小时的暴力，反而比喀耳刻少
佩涅洛佩≥39伊萨卡簇约 119 条，只有屠杀求婚者是暴力的
卡吕普索≥17跨九种以上媒材与地区，不是「没人画」
食人族 Laistrygones1全诗最暴力的一段，一件存世，还是罗马的

方向是反的。不能用。

✓ 换成这条——它更准，而且它为这个网站的存在方式辩护

古代艺术只有一个时态。
他们画了卡吕普索十七次——每一次都是他离开的那一刻。
七年没有那一刻，所以七年画不出来。

Rafn：存世的卡吕普索图像「几乎全部集中在奥德修斯离开她的时刻」，没有任何一件确证的古代作品画的是坐着的卡吕普索。Lowenstam 给出机制，一句话："Art has only one tense."

这就是「为什么必须是交互，不能是一张图」的答案。这个网站在做瓶画做不到的事：把时长本身变成可以看见的东西。

为什么食人族只有一件

不是不暴力，是不可辨识。Woodford 的可辨识性论：奥德修斯藏在公羊肚子下被反复画，因为「一个人倒吊在羊肚子下」这个画面自己在喊「这里有事发生」。而扔石头的巨人和任何一场巨人之战长得一样，没有辨识特征。

为什么不能从存世量读偏好

三万多件希腊陶器出自伊特鲁里亚墓葬，而伊特鲁里亚人只买杯不买瓶。伊特鲁里亚版奥德修斯（Uthuze）≥148 条，对比希腊版 ≥191 条——一大半「奥德赛图像学」反映的是伊特鲁里亚人的丧葬需求，不是希腊画师的偏好。

实操：14 站的图像可得性

5充分存世
6稀少
3未找到

食莲人、基科涅、卡律布狄斯、太阳牛、奥吉吉亚在 LIMC 里连条目都没有（卡吕普索归在 Kalypso 条下）。奥吉吉亚虽有 17 件，但没有一件在 Commons 上有自由授权照片——实际上仍然无法用古代图像呈现。

结论：混合方案，而且缺口本身是内容

  • 有充分瓶画的站点（独眼巨人、塞壬、喀耳刻、斯库拉、冥府）→ 真实瓶画抠图，Deep Sea 的方法。红绘本来就是平涂橙色人物压在纯黑底上，是最适合抠图的美术源。逐件核照片授权，标注馆藏与编号。
  • 没有古代图像的站点（奥吉吉亚、食人族、太阳牛…）→ 不要硬画一张。留一个空面板，写 no surviving ancient depiction 并说明原因（无条目 / 无自由授权照片 / 不可辨识）。
  • 于是奥吉吉亚那七年既没有时长刻度、也没有图像——时间轴上是斜纹，画面上是空白。两条轴讲同一件事。

配色沿用红陶体系（--slip #1c130d / --clay #c1632c / --gold #d1a13a / --parchment #f2e4c4）。每张图必须有 alt——spec/invariants.test.ts 硬检查。外部图片会拖慢首屏，而「慢连接」在评分标准里，所以抠图要压到 WebP 并控制总量。

数据模型

// src/data/voyage.ts — 唯一的事实来源，全部可回溯到 research/

type Beat = {
  caption: string;        // 从 research 提炼的散文，已有 29 段可复用
  days: number | null;    // null = 原文没给时长，不许填数
  art: ArtId;             // 内联 SVG symbol 的 id
  alt: string;            // invariants 硬性要求
};

type Stop = {
  id: string;
  name: string;
  book: string;           // "Book 9" — 面板上直接显示出处
  mapX: number; mapY: number;
  weight: "headline" | "brief";
  beats: Beat[];
};

type Ghost = {
  arrivalDay: number;
  source: string;         // "Odyssey, Book 3" 或算式本身
  inferred: boolean;      // true 时页面上必须打 inferred 标记
};

// 派生量，全部从 beats 算出来，不手写：
//   dayAt(beatIndex)      当前真实天数
//   behindBy(beatIndex)   dayAt - ghost.arrivalDay  ← 头条数字
//   TOTAL_STATED_DAYS     3034（由 beats 求和校验，不是常量）

一条应该写进 CLAUDE.md 的规则

TOTAL_STATED_DAYS 不能硬编码成 3034，必须由 beats 求和得出，然后写一个测试断言它等于 3034。这样任何人改了某个 beat 的天数，测试立刻红——数据和展示不会偷偷脱节。

这类"把修正落在 harness 上而不是重试上"的动作，正是 brief 里点名的 HD 级 process moment。

08

把"没有数据"设计成特征

research 明确记录：18 项里有 8 项原文没给时长。CLAUDE.md 也写死了"Gaps stay gaps，不许插值"。与其藏起来，不如让它成为论点的一部分：

  • 日历行上，无时长的段落渲染成斜纹最小宽度，标注 duration not stated in the text
  • 于是独眼巨人在时间尺上几乎看不见——"最著名的一段，荷马没说它花了多久"本身就是内容
  • 页脚直接写出缺口：诗中框定为十年；文本给出明确时长的部分合计 8.3 年；剩下 1.7 年（17%）没有任何依据可以填。
  • 任何我算出来的数（幽灵船基准线、航迹距离）全程带 inferred 标记，并可展开看算式

这一节不是免责声明，是加分项。marker 读到的是一个知道自己知识边界在哪的作者，而不是一个把表格填满好看的作者。

09

无障碍与"没为它设计的用法"

artefact 那 20% 的 HD 条件原文是：holds up under use it wasn't designed for — 键盘、交互中途 resize、慢连接。逐条对：

键盘

  • 用原生 <input type="range">，W3C 明确建议不要自造 ARIA slider
  • 方向键 = 逐 beat，PageUp/Down = 逐站，Home/End = 首尾
  • aria-valuetext 播报语义而非数字：
    "Beat 12 of 26. Circe, year one. Day 47. 30 days behind."
  • #scene 用 aria-live="polite"

Resize / 慢连接 / 动效

  • 状态只有一个整数 beatIndex，布局是纯 CSS Grid → resize 天然不掉状态
  • 全内联 SVG，零图片请求；单页单 JS 模块
  • 不加 webfont，用 Georgia / Palatino 系统栈
  • prefers-reduced-motion 下船瞬移不补间，内容一个不少
